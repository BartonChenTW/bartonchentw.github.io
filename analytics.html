What is recorded

  • One page view per page load, per page path.
  • Visitor country, as reported by GoatCounter, plus referrer, browser and screen size in its standard reports.
  • No cookies and no tracking of individual visitors. Local previews are not counted.

Reading the numbers

  • Log in at goatcounter.com, then open the dashboard of the site you want.
  • A page view is not a person. The same visitor can add several views, and visitors who block scripts are missed.
  • The public “N views” counter is off. The counter address answers 403 until “Allow using the visitor counter” is switched on in each site’s GoatCounter settings. FM4UES already has the code ready and shows the count once it is.

Counting this site too

Create a GoatCounter site (for example bartonchentw) and add one line to each page: <script data-goatcounter="https://bartonchentw.goatcounter.com/count" async src="https://gc.zgo.at/count.js"></script>. It belongs on all four pages, English and Chinese.
